# Maestro

Installer e aggiornamenti ufficiali di Maestro per Windows con motore WSL.

Scarica l'installer dalla [release più recente](https://github.com/MattiaPaiano91/maestro-releases/releases/latest). Non serve un account GitHub per scaricare o aggiornare l'app.

Servono Windows 10/11, WSL 2 e Codex installato e autenticato nella distribuzione Linux. Gli aggiornamenti verificano la firma del pacchetto prima dell'installazione.

Questa repository distribuisce solo pacchetti compilati, firme e manifest. Il codice sorgente è mantenuto separatamente e resta privato. La disponibilità pubblica dei pacchetti non concede una licenza sul codice sorgente.

Le versioni fino alla 1.2.7 richiedono l'installazione manuale della 1.2.8 o successiva per passare agli aggiornamenti senza login GitHub. Chat e impostazioni esistenti vengono conservate.
